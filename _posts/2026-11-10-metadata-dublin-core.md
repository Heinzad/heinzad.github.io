Metadata describes data. Without it, data can become meaningless. 

Dublin Core is a useful place to start if you have no subject-specific metadata standard to follow. 

It can be written in plain text in the form `label (content)` or `label includes (range)`. 


### Key Terms 

A selected list of metadata terms that are particularly useful for describing structured data: 

| Attribute | Description | 
| --------- | ----------- | 
| Subject | A topic of the item |
| Title | The name of the item | 
| Description | A free-text account of the item | 
| Definition | Represents the concept and essential nature of the item | 
| Type | Includes (property, class, data type or encoding scheme) | 
| Domain | The class of which the item is an instance | 
| Coverage | Spatial or temporal topic of the item | 
| Audience | Those for whom the item is intended | 
| Publisher | The person or organiation responsible for making the item available | 
| Contributor | A person contributing to the item | 
| Creator | The person or system that created the item | 
| Created | Date of creation of the item | 
| Modified | Date on which the item was changed |
| Valid | Date range in which the item is valid |
| Provenance | Canges in ownership and custody of the item since its creation that are significant for its authenticity, integrity, and interpretation. May include a description of any changes successive custodians made to the item | 
| Source | A related item from which the item is derived | 
| Reference | A related item that is referenced, cited, or pointed to by the item | 
| Equivalent | An equivalent property to the described item | 
| See | Authoritative documentation for the item | 
| Access | Who may access the item. Includes (access rights or restrictions based on privacy, security or other policies) |
| Rights | Includes (intellectual property rights) |
| Identifier | Name used in the Uniform Resource Identifier | 
| URI | Uniquely Identifies composed from namespace and identifier |
